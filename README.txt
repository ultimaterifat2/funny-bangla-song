FUNNY BANGLA SONG — APP
========================
1) Netlify-তে এই folder/ZIP upload করে publish করুন.
2) Chrome Android-এ site খুলে INSTALL APP চাপুন.
3) Registration/Login browser local storage-এ demo হিসেবে কাজ করে.
4) Profile > Admin Panel > password 1080.
5) Admin Panel থেকে sound-এর নাম, category এবং audio file select করে Save Sound দিন.
6) Seed audio files এই package-এ assets/audio/ এ আছে.

IMPORTANT:
এটি একটি static Netlify demo. Admin-added sounds/users browser-এর local storage-এ থাকে, তাই অন্য device/user-এ নিজে থেকে sync হবে না।
Production version-এ Firebase/Supabase বা অন্য backend লাগবে।
